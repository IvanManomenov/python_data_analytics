# python_data_analytics

Лабораторные работы по анализу данных на Python. Вариант М — «Экономика городов».

| Папка | Тема |
|---|---|
| [lab1](lab1/) | Иерархическая кластеризация |
| [lab2](lab2/) | K-means |
| [lab3](lab3/) | DBSCAN |

В каждой папке находятся самостоятельный Jupyter Notebook и исходный `Econom_Cities_data.csv` из выданного учебного архива. Все три работы используют один и тот же набор данных: 48 городов, 1991 год, признаки Work, Price и Salary.

## Данные

Разделитель — `;`, десятичный разделитель — `,`. Код пропуска — `-9999`. Исходные значения сохранены без изменений. При анализе Cairo и Jakarta исключаются из-за отсутствия двух из трёх признаков; в основной выборке 46 городов.

## Запуск

Открыть ноутбук нужной лабораторной в Jupyter или Google Colab и выполнить ячейки по порядку. Локально установить зависимости: `pip install -r requirements.txt`.

Общий выполненный ноутбук в Colab: https://colab.research.google.com/drive/1YmLRnTUKYjHDuZKqWmSx1PPgaVw2eysm
